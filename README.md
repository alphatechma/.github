# .github

Arquivos de comunidade e perfil público da organização **AlphaTech**.

- `profile/README.md` — apresentação exibida na página pública da organização
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` — guias aplicados a todos os repositórios
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` — templates padrão da org

O perfil interno, visível apenas para membros, fica em
[`alphatechma/.github-private`](https://github.com/alphatechma/.github-private).
